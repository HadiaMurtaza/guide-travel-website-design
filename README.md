# guide-travel-website-design
A modern travel website landing page built with HTML and CSS.


## 📌 About the Project
Guide is a modern travel website landing page designed to help users explore destinations and plan their dream trips. It features an attractive layout, travel images, and navigation links to create a simple and user-friendly experience.

This project was created to practice front-end web development skills and improve website design.

## ✨ Features
- Clean and modern user interface
- Navigation menu with multiple links
- Login and Sign Up buttons
- Attractive travel-related images
- Travel categories, including:
  - Waterfall
  - Guide
  - Staycation
  - Hotel
  - Destination
  - Tour
- Simple and user-friendly layout

## 🛠️ Technologies Used
- HTML5
- CSS3


## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Find the `index.html` file.
4. Double-click `index.html` to open the website in your browser.


## 📁 Project Structure

guide-travel-website/
├── index.html
├── style.css
└── images/




## 🎯 Project Purpose
The purpose of this project is to practice HTML and CSS, learn website layout and styling, and develop a visually appealing landing page.
